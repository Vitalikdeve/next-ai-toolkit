# Contributing to next-ai-toolkit

Thank you for your interest in contributing to `next-ai-toolkit`!

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Vitalikdeve/next-ai-toolkit.git
   cd next-ai-toolkit
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the test suite:
   ```bash
   npm test
   ```

## Pull Request Guidelines

- Ensure all existing tests pass (`npm test`).
- Add unit tests for any new features or bug fixes.
- Follow TypeScript strict typing standards (`npm run typecheck`).
